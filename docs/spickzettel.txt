1) DER ABLAUF (mehr ist es nicht)
----------------------------------------
1. Nachricht kommt
   -> EINE Stop-Order auf das genannte Level legen

2. Meldung "Level verschoben"
   -> Order nachziehen

3. Order loest aus
   -> Position dreht, neues Level kommt
   -> zurueck zu 1.

Kein TP. Kein manuelles Schliessen.


2) SITUATION -> AKTION
----------------------------------------

Du startest gerade, Indikator zeigt
schon eine Position
   -> NICHT einsteigen. Warten, bis das
      naechste Signal ausloest, dann frisch
      mitgehen.

Neues Level gemeldet, du bist flat
   -> Stop-Order auf das Level legen,
      Groesse nach Formel oben.

Du bist LONG, Sell-Stop UNTER Einstieg
   -> Nichts tun. Das ist dein geplantes
      Risiko (30 $).

Du bist LONG, Sell-Stop UEBER Einstieg
   -> Nichts tun. Gewinn ist gesichert,
      laufen lassen.

Level zu deinen GUNSTEN verschoben
(Long: hoeher / Short: tiefer)
   -> Order nachziehen.

Level zu deinen UNGUNSTEN verschoben
(Long: tiefer / Short: hoeher)
   -> Order STEHEN LASSEN. Niemals das
      Risiko nachtraeglich vergroessern.

Position im Minus, Stop rueckt naeher
   -> Nichts tun. Ausstoppen lassen.

Preis naehert sich TP1 / TP2
   -> Nichts tun. Die TPs sind nur
      Orientierung. Mitnehmen kostet ca.
      19 Prozentpunkte Erfolgsquote.

Bot war offline / Signal verpasst
   -> Nicht nachtraeglich einsteigen.
      Auf das naechste Signal warten.

Drawdown naehert sich 6 % (-600 $)
   -> Handel pausieren. Die Challenge hat
      kein Zeitlimit; ein Bust ist endgueltig.

Tagesverlust naehert sich 3 % (-300 $)
   -> Fuer den Tag aufhoeren.
      Reset ist 00:30 UTC.
